# Human Gunner 1.20.1 port

This is a compatibility port of Human Gunner by AmarokIce. The supplied
1.18.2 JAR declares the project under MPL-2.0; its CurseForge project page
lists the project under the MIT License. This port retains the original
package and mod identifiers for save and configuration compatibility.

The 1.20.1 implementation was rewritten against Hostile Humans 1.2.4+
(the TAVO2-compatible 1.4.13 build) and TaCZ 1.1.8. Guard Villagers support
from the 1.18.2 build is intentionally omitted because that optional mod is
not installed in the target pack.

Original project: https://www.curseforge.com/minecraft/mc-mods/human-gunner
MPL-2.0: https://www.mozilla.org/MPL/2.0/
