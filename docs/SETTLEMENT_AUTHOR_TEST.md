# 据点作者工具验收

使用新版本 JAR 的独立创造测试世界。启用作弊或使用有操作员权限的创造玩家。模板文件入口沿用原版结构保存与放置所需权限。

## 建立一个可操作的二阶据点

1. 搭一个小院，入口留出高度。放「据点信息方块」、赤獠控制台、贡献箱、阵营商店和训练中心。创造栏取「建筑框选器」和「建筑模板放置棒」，放到快捷栏。外圈放贡献箱和商店，内圈放训练中心。
2. 右键信息方块，在身份页把模板 ID 改为 `hostile_humans_unified:author_test`，类型保留 ROOT，阵营用赤獠，阶级设为 2。填好后可直接点「在世界中框选建筑保存范围」，服务端会先保存草稿，再配置框选器。
3. 点「在世界中框选建筑保存范围」。界面自动关闭。手持分区工具右键点两角，绿色框跟随准星并在第二角后固定。再右键一次保存，左键取消本次未保存的选区。角点是所点击的方块，两个端点都计入尺寸，结构框必须包含信息方块。
4. 打开区域页，先点「新增区域」，选择外圈。可以直接点「将建筑范围用作当前外圈」，或选包含框组再点「用世界框选向当前包含／扣除框组追加」。选择包住外院及设施的两角后确认。新增区域，把层级从 OUTER 改成 INNER，保存表单后以同样方式选内圈。补缺用追加，挖空用扣除，单独改一个框用「在世界中重选当前选区框」。
5. 从设施页点「在世界中点选设施方块」，持工具依次右键控制台、贡献箱、商店和训练中心。若提示多个合法区域，在区域页选中你想用的区域，再点「在世界中点选设施，优先绑定此区域」。已有锚点可选中后实景移动，ID 保留。N2 入口和 N5 岗位由设施页创建为坐标锚点，也可选中后实景移动。
6. 打开保存与登记页，点击「登记当前建筑为新据点」，按提示再次确认。核对管理页的设施和原因。日后修改已登记据点，保存草稿后用「更新绑定模块」。
7. 在独立测试世界可用 `/hh standing set @s hostile_humans_unified:crimson 250`。空手右键赤獠控制台检查真实管理页。贡献箱和商店走正式经济权限与配置，默认正式价格策略关闭。需要测交易 UI 和测试报价时，用创造测试入口 `/hhu economy test crimson`。训练还要满足内圈、二阶及相关训练条件。

## 直接使用建筑框选器

手持框选器潜行右键信息方块，绑定当前建筑。再潜行右键空气或其他方块，打开框选面板。可选建筑保存范围、追加或替换区域框、设施点选或仅查看。外圈、内圈、扣除区、保存范围与设施分别开关，区域标签显示名称和编号。回信息方块的区域页可根据相同名称与编号修改或删除。测试切换到放置棒后，框选器的绑定和未确认角点是否保持。

## 保存、搬运与回归

- 保存与登记页用「保存建筑到 NBT 文件」。默认只抓方块和方块实体。需要捕获样板生物时打开「包含实体」，使用专门布置的样板生物。文件在存档目录的 `generated/<命名空间>/structures/<路径>.nbt`。同名世界文件通过独立覆盖按钮确认；数据包文件由数据包维护。
- 手持建筑模板放置棒潜行右键空气，打开模板放置面板。可点选已保存模板或手填 ID，并设置旋转、镜像和实体。开始选点后，右键目标表面显示半透明预览，普通右键可改位置，潜行右键确认，普通右键空气取消。目标处无需预放信息方块，模板自带的那块用于编辑和登记复制品。建筑棒会在本次进入世界期间记住放置选项。
- 也可以去一片空地，执行 `/hh settlement template preview hostile_humans_unified:author_test ~ ~ ~`。目标位置是旋转后建筑范围的最小角。白框为放置范围，30 秒内用 `/hh settlement template confirm` 放置，或用 `/hh settlement template cancel` 取消。放置会替换框内的目标方块，请用独立测试区。
- 再测旋转镜像，例如 `/hh settlement template preview hostile_humans_unified:author_test ~ ~ ~ 1 front_back false`。检查分区框、设施、实体与建筑的相对位置。数字 0–3 是顺时针四分之一转次数，镜像选项为 none、left_right、front_back，末尾 true 才加载实体。
- 加载后的信息方块保留作者草稿，点击登记后应获得新的据点身份。原据点的设施和状态仍在其原位置。测试放置点在已有信息方块上应被拒绝。
- 测越界设施、错阵营控制台、未加载区块、多人修改过期草稿、撤销选点和默认外圈替换。把贡献箱放到只属于内圈的位置，应无法绑定为补给设施。
- 文件操作最多每轴 512 格、总计 262144 格。要求相关区块已加载。编辑器支持单模块作者模板；已登记且旋转或镜像的模块请用独立作者副本导出。

## 数据怎样关联

信息方块持有模板局部坐标和作者修订，世界点选经当前摆放的逆变换转换成局部坐标。区域是包含框并集减去扣除框，设施锚点引用稳定区域 ID。预览用服务端确认的框，第一角后准星所指的临时第二角仅用于显示。

结构 NBT 保存建筑、方块实体和可选实体。导出副本移除信息方块的正式实例 UUID 与模块引用；加载时把分区和设施按与建筑相同的旋转镜像归到新的模板原点。放置和登记是两步。登记把数据写入所在维度的正式索引，运行时功能方块用自己的坐标、类型、阵营和权限查索引。只放实体方块、只保存草稿、或刚加载 NBT 时，都可能看到未登记。
