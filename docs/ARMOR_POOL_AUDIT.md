# 默认护甲池与阶级核对

核对日期：2026-10-11。基于当前源码默认资源、测试实例中的Immersive Armors 1.7.2和Scorched Guns 0.5.5 JAR。此表为原生基础护甲点数，2点对应1个护甲图标；不计韧性、附魔、套装特殊效果、成长早期替换、数据包或其他模组对属性的修改。跨模组不能仅凭护甲值判断最终承伤。

## 调整结果

- 四阶所有原版默认套装、沉浸式和焦燃自动导入套装，逐条权重统一为1。同一阶级已加载、物品齐全且部位正确的套装等概率；缺少前置的条目不会占抽取权重。
- 流浪者皮革6、锁链3调整为1；三阶下界合金186、沉浸式各38调整为1。其他原本为1的条目保留。
- 焦燃Scrap套真实护甲21点，移出流浪者/一阶，改为三阶；沉浸式凋灵套11点从二阶移到一阶。其他已有阶级归属保留。低阶保留弱装备、高阶允许部分重叠；不承诺高阶任一随机套都强于所有低阶套。
- 一个条目对应一套完整装备组合。Iron Mask/Brass Mask/Ridgetop为不同头部搭配，不是额外整套材质；它们各占一个等权条目，相同胸腿靴的合计概率会更高，但没有巨大的单项权重。
- 外骨骼不导入；Spartan Weaponry和Spartan Shields在本模组的默认接入负责武器和盾牌，没有自动导入护甲套。

## 配置与实际生成的边界

生成先由ConfiguredEquipmentLoadout.Pool过滤可用条目并按weight抽整套，ConfiguredHumanEquipment按四部位装备；NaturalEquipmentGrowth随后可能按早期材质保留概率把整套替换为各阶早期护甲。因此等权是原始套装池机会，早期看到的成品不一定等概率。成长满进度后不再做此早期替换。本轮未改变成长概率、附魔或护甲本身的属性。

已有各阶配置和导入记录按现有规则保留，不强制改写玩家的权重、增删套装或完成过的导入；本轮只更新打包默认和首次导入模板。测试实例当前文件仍有旧权重/旧阶级归属，尚未修改，也未构建/同步。

## 来源与验证

- src/main/resources/defaults/hostile_humans_unified.json：equipment_loadouts.*.armor_sets。
- src/main/resources/defaults/equipment_integrations.json：两种联动逐阶元组。
- EquipmentIntegrationDefaults：一次性追加导入，已有用户权重及空池不覆盖。
- ConfiguredEquipmentLoadout.ArmorSetEntry/Pool、ConfiguredHumanEquipment、NaturalEquipmentGrowth：过滤、抽取、装备、成长替换。
- 实际依赖JAR的immersive_armors.Items、ExtendedArmorMaterial：protectionAmount参数及槽位映射。
- 实际依赖JAR的top.ribs.scguns.init.ModArmorMaterials/ModItems：材质护甲数组、Type.ordinal顺序和混搭头部实际材质。

本轮为静态资源与只读字节码核查，不证明运行时外部配置修改后的护甲值。未执行Java编译或游戏抽样测试；待用户要求构建后验证新生成单位。
