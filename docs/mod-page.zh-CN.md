# 模组站介绍（简体中文）

## 简介

由原模组 [Hostile Humans](https://www.curseforge.com/minecraft/mc-mods/hostile-humans) 修改衍生，整合 **Human Gunner** 的相关内容，并加入原创玩法。Hostile Humans Unified 是一个可独立安装的 Forge 模组，不需要另外安装上述原模组。

## 内容介绍

模组加入流浪者、一阶、二阶和三阶人类。不同阶级拥有不同的属性、装备与战斗能力。身份牌和阵营关系会影响人类对玩家的态度；玩家可以使用合同雇佣人类，并通过对讲机查看和管理士兵。

已雇佣的人类可以执行跟随、区域驻守、原地驻守和巡逻命令，并在主动攻击、被动保护与完全中立模式间切换。玩家可以打开士兵背包，管理装备、设置主动拾取，或解除雇佣。

人类会根据装备使用近战武器、盾牌、弓、弩、三叉戟或枪械。低血量时会撤退并尝试恢复。信号弹可以召来临时援军或敌对人类；对讲机可以查看士兵状态并召回他们。

## 可选兼容

TaCZ 提供枪械兼容，Better Combat 提供士兵近战兼容，Curios 提供身份牌饰品栏。安装 Spartan Weaponry、Spartan Shields 或 Immersive Armors 后，会自动识别兼容的武器、盾牌和盔甲。这些模组均为可选项，不是运行本模组的必需依赖。

适用于 Minecraft 1.20.1 和 Forge。详细配置说明见[配置指南](../CONFIGURATION.md)。
