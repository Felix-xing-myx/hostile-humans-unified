# 枪手局部机动与贴身试射

2026-10-11源码实现，未构建、未投放，游戏行为待验收。TaCZ与Scorched Guns共用此入口；弓弩的RangedMeleeCycle不变。

`CloseGunTactics`只管理局部机动和切换时机。`GunCustody`仍管理实际武器交换，`CloseDefenseHold`和Human的延迟近战仍决定攻击何时完成，`ShieldDefenseController`仍独占举盾、防御朝向与反击窗口。没有第二套伤害、换弹或盾牌系统。

## 局部机动

原枪手后撤反复搜索16格随机远离点，现改为围绕本次局部交战起点的8格水平半径进行迂回，每次侧向约3格、向外约0.75格；超过边界的候选收回到半径7格处。完整路径各节点都必须符合半径、士兵命令区域、地形安全和有限退路规则。最多每8 tick尝试一次，每次最多两个候选，计入现有服务器RETREAT公平预算；已有合格活动路径继续走，不反复重置。没有安全路径就留在当地交战，不继续执行无限后撤小步。

局部状态由弱引用持有，短暂盾牌Goal抢占不重置起点；超过120 tick未参与局部决策时重新建立。目标远离后的正常追击、真正低血撤退、上岸及驻守归位仍由原控制器负责，因此这里的8格约束专指本入口产生的机动路径，并非限制所有外力/生存行为。

## 贴身试射与退回防御

- 持续近战至少60 tick后，可在视线通畅、近战保留期结束、没有未完成的Better Combat前摇、没有高压防御需要时尝试恢复枪械。先通过统一盾牌入口释放其自身的格挡，不中断食物、药品或其他控制器的使用。
- 成功恢复到枪械且敌人在6格内时，进入100 tick近距离试射观察期；原距离出口恢复枪械也使用同一观察入口。期间普通贴近条件不立即把枪换回近战，高压生存策略仍可抢占。
- 观察期内按实际生命损失统计最近20 tick：至少2次有效敌对命中、累计损失达到最大生命20%，或至少3次、累计损失达到10%，就视为持枪保护不足。环境和友军伤害不触发，取消/完全格挡的零损失不计；样本最多64条。不要求损失来自当前目标，同场其他合法敌人的攻击也算。
- 下一次战术处理切回已有近战武器，并保持至少100 tick再考虑试射。盾牌使用现有完整主动防御和反击窗口，受击安静后按原规则收盾反击；不增加盾牌减伤、不保证百分之百格挡。低血撤退仍优先。没有可用备用近战武器时不创建物品，保留现有回退。
- 交换实际枪械仍由GunCustody完成，后台换弹保留原枪堆栈和交易，不重新扣弹匣，不重置装填进度。

以上距离、窗口及损失阈值当前是CloseGunTactics代码常量/规则，并非新增配置项；现有射程、盾牌、高压、弹药配置继续生效。
