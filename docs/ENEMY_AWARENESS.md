# 敌人感知源码地图

玩法手册：`E:\个人知识库\Hostile Humans Unified\02-战斗与生存\敌人发现、警觉与锁定.md`；开发手册：`05-开发参考/敌人感知原理与修改入口.md`。导航诊断见 [NAVIGATION_DEBUG.md](NAVIGATION_DEBUG.md)。

## 入口 → 条件 → 状态 → 消费

`Human`服务端tick推进`HumanPerception.tick`；声音适配、真实受击与主人事件请求观察或线索，只有共同边界能够把目视证据转为已确认目标。目标Selector、增强战术、护卫与武器执行不能仅因持有LivingEntity就取得合法实时位置。

| 责任 | 入口 | 必须保持的约束 |
|---|---|---|
| 参数 | `PerceptionConfig`、`UnifiedConfig.perception()` | 全局不可变配置快照，默认值、范围、说明集中；完整重启生效 |
| 时序与几何 | `PerceptionPolicy`、`RecognitionEvidence`、`BodyVisibilitySamples` | `now < until`才动态有效；伤害只续有效期；组合系数独立收敛；三个距离锚点间插值视角 |
| 视觉/识别与知识 | `HumanPerception.tick/check` | 敌我、同维度、范围、朝向、原版可见度、方块COLLIDER射线；预算不足不视为成功 |
| 攻击准入 | `HumanPerception.canTarget`、`Human.setTarget` | 已标记且动态有效，再复核存活、同盟、模式与命令；确认不代替许可 |
| 合法位置 | `HumanPerception.knownPosition` | 动态期内真实位置，到期只最后位置，不可把线索UUID解析为实时导航目标 |
| 受击与回看 | `HumanPerception.hurt/finishLook`、`PerceptionLookGoal`、`AttentionFacingPolicy` | 弹丸方向快照、无可靠方向安全降级；首次识别受保护；其他来源排队 |
| 声音/求援 | `HumanAwareness`、方块/通道Mixin、事件入口 | 点时线索、同源去重、有界排队；平静/警觉均监听脚步，线索LOOK独立于MOVE；友军求援不转交攻击者 |
| 调查移动 | `PerceptionInvestigationGoal`（旧调查Goal入口委托） | 只消费位置；复用BasicNavigationBudget、HumanTerrainSafety与RetreatPathSafety；仅停止自己拥有的路径 |
| 信标报告 | `BeaconReportingService`、`BeaconReportPolicy`、`HumanSignalItem` | 仅成功生成后used；同玩家/维度通道；周期/报告TTL/发报总期限分开 |
| 战术与动作 | `AdaptiveCombatGoal`、盾防/武器/护卫入口 | 继续现有威胁排序，所有目标/位置须共同准入；LOOK让位于首次识别，MOVE保留安全与命令 |
| 诊断 | `PerceptionDebugSnapshot/Codec`、`NavigationDebugService/Client`、`NavigationDebugViewPolicy` | 服务端只读快照，客户端只显示；分页/焦点切换不下达行为命令 |

识别使用归一化证据量。只有实际检测发现出视野或遮挡，才开始连续失去视觉的计时；达到10tick清零。短暂遮挡保留已得进度但暂停累计。尚未轮到检测或预算不足只表示未知，不能当作已经被遮挡，也不补算等待期间的长时间证据。首次看见候选后改用活跃采样间隔（默认4tick），避免平静10tick间隔与中断阈值相撞。

每个人类最多同时推进两个目标的视觉识别，分别保存进度、遮挡起点和期限；识别完成不等于能同时攻击两个目标。一个主观察目标控制转头，保持首次识别保护；另一个目标只有仍在实际视场内且无遮挡才推进，不能为了同时识别去读背后或墙后的坐标。头盔显示“并行视觉识别 数量/2”以及各目标的进度和主观察归属。

陌生目标的默认完整视场角按三个人类眼部至检测点距离锚点确定：8格及以内160°、32格处120°、64格及更远90°；8～32格、32～64格之间线性过渡。例如20格140°，48格105°。这里是完整夹角，判断时换算为半角，仍是三维圆锥。旧敌默认半角乘1.2，最多90°，对应完整夹角近处180°、32格144°、64格108°；旧配置的上限也不能把旧敌视野缩得比陌生目标更小。几何视野仍须真正无遮挡，潜行/隐身的原版可见度修正仍适用。

识别证据按每次真实检测推进，不从预算等待时间补足。每人默认一轮最多2个快速候选，身体补查最多27条/目标且同占总池，平静10tick、活跃4tick；邻域查询、射线、线索投递和移动声源分别受每维度及全服务器配额限制。默认每维度/服务器每tick为查询64/128、射线128/256、线索256/512、声源128/256；事件查询最多占25%。这些仅约束新增感知工作量，不涵盖原有战斗、寻路等所有查询；不是公平延迟或毫秒性能保证。

身体可见性不再要求露出眼睛。先检查上次可见部位（没有记录时先看眼部），不通时补查逻辑包围盒的3×3×3采样点，覆盖躯干中心、上下/左右表面、边心及角点；任何采样点在有效距离和视场内、且人类眼部到该点无遮挡，就在本次采样开始或继续识别，不必等待头部露出。主观察注视已露出的部位；下一次优先复查该部位，并随实体位置/姿态的包围盒变化更新。

这不是立即激起仇恨：仍需累计识别进度，仍检查关系/攻击许可。平静检测默认每10tick，识别中每4tick；候选轮转和总配额可能带来调度等待。采样依据逻辑碰撞体，不能保证命中任意细小缝隙或碰撞体外的模型、武器、装饰像素。视觉发现也不替代实际射击弹道/命中检查。

每人每轮默认最多检测2个快速候选。快速部位不通时，`perception.budgets.body_rays_per_target`默认允许该目标补查最多27条射线（范围1～27）；发现可见点立即停止。快速与补查共同受每维度128/全服务器256条每tick的原射线池约束，配额按保守申请量扣占，不是无上限追加。补查用完便取消下轮预留；未拿到配额不记为遮挡，低配额只完成部分点时轮转补点，不把尚未检查的身体判为全遮挡。

## 状态归属与保存

`HumanPerception`逐实体弱引用状态包含独立目标Track（确认、动态/最后/旧敌期限、归一化进度、独立RecognitionEvidence）、线索、待观察来源、LOOK归属和有限转换记录。目标死亡、无效、关系变化与过期在服务器维护；主人/行动命令变更清掉旧知识、观察与攻击目标。普通感知不写NBT，卸载不恢复未完成识别。

`BeaconReportingService.Store`通过主世界SavedData保存通道，键为玩家UUID与使用维度；保存最后成功使用、总截止、下次发报、报告序列、采样时刻、报告截止和网格坐标。成员NBT存追捕玩家与使用维度，旧实体有追捕UUID时以当前维度补兼容身份；接收去重是临时状态。使用全服主世界游戏时钟，重载只恢复剩余期限，不重新起算。招募或有效主人出现时删除实际追捕目标，出生来源标记的掉落语义另留原处。

## 同步与诊断

只有有效观察者才生成并发送有界快照，默认5tick间隔，最多8个人类。导航通道协议4的帧携带同实体的感知快照，客户端3秒没有新帧时隐藏旧数据；目标身份/位置按知识阶段裁剪，未知方向不发送隐藏射手身份坐标。每页只筛选已收到字段，不为了展开详情重扫实体、补射线或重算路径。最近状态转换最多32条/20秒；感知射线只显示近期已有样本，几何视锥与真实无遮挡证据分别渲染。调试快照与观察选择不作为持久AI状态。通道4新增唯一空负载C2S焦点轮换请求，服务器检查头盔、权限和自己的当前维度观察会话；快照仍仅S2C。

F8六页为概览、目标/记忆、视野、声音/信标、动作/导航、预算，可选择世界标记层与焦点。动作页读GoalSelector实际运行集合、priority、控制标志及手部占用，并显示战术压力/记忆数量与锁定剩余，决策意图不能代替当前MOVE/LOOK任务；固定点测试暂停自主观察并明确显示接管。

平静和警觉的人类都能接收附近非友军的普通脚步/奔跑落地/水声。声音先产生位置线索和警觉，随后可以转向声源当时的位置；不会凭声音确认敌对身份或直接锁定，也不会在声源停止后继续读取其隐藏实时位置。

转头独立于调查移动：原地驻守也能回头观察，但仍不离岗。新线索或线索位置移动超过2格时请求短暂注视，默认最多40tick（2秒），不同线索的回看至少间隔20tick（1秒）；同一固定位置不会每tick重复抢头。调查移动中的观察可以持续到该任务结束。首次视觉识别/受击观察、当前战斗目标、撤退以及睡眠/NoAI/固定点测试优先；是否走过去继续由原命令与安全路径决定。

脚步是服务端模拟：需要真实累计位移（普通0.8格、奔跑0.6格、游泳1格），初次采样先建立位置基线，平静邻域默认10tick、活跃4tick，另受声源冷却与全局配额约束。因此不是任意音效播放即触发。默认仍忽略本人、已知友军普通脚步、潜行/无声、创造/旁观玩家，以及受击位移/超过8格的传送跳变；枪声后端仍未接入。

受击回看分为“请求观察”和“落实朝向”。真实有效受击先进入警觉；近战根据命中方向，弹丸根据来袭轨迹反方向观察。观察Goal占用LOOK，随后在服务端实体tick末尾落实旋转，每tick最多一次，头部最多45°、身体最多30°、俯仰最多35°；继续遵循原版头身夹角上限。连续观察保留自身转向进度，避免移动控制每tick写回朝向而转不到身后。身体转向用于非撤退的观察或无攻击目标状态；撤退继续保留移动朝向，不改路径/坐标/速度。

没有合法攻击对象也可以回看可靠来袭方向。例如创造模式玩家造成实际伤害时，可以获得最长40tick（2秒）的匿名方向观察，普通声音不能覆盖它；该观察不授予对创造玩家的攻击许可，也不读取未知枪手坐标。首次已受保护的观察仍不被后续来源伤害抢断。无可靠方向的未知弹丸只警觉，持续伤害不伪造新方向。取消、免疫或主人保护挡掉的伤害不算此次真实命中；NoAI和固定点导航测试仍不强行解除。

## 失败路径与修改约束

- 敌我或主人许可过期：清目标/拒绝攻击，知识不自动续权；位置调查仍单独受命令约束。
- 未知弹丸无有效速度、无可靠来源或周期伤害：保留警觉，不补出隐藏射手位置。
- 识别遮挡10tick、方向2秒、识别任务6秒：释放占用，后续排队来源才有机会处理；不借重复伤害无限延长本次占用。
- 动态截止tick起：伤害不能复活实时位置；回看方向后依实际目视恢复。其他目标不联动续期。
- 查询/射线/导航配额不足：等待，不记为检测成功、识别完成或路线不可达。
- 无安全落点、区块未加载、命令不允许或路线不可达：有限重试并结束；不强加载、不传送、不拆墙，也不停止另一控制器的路线。
- 信标无有效通道/玩家离线或跨维度/成员受控/超范围：不接收报告；观察详情只读，不创建通道、发报或清理存档。

扩展新事件应先回答它提供的是许可、方向、静态位置还是合法动态知识，再接共同入口。不得新增绕过`canTarget/knownPosition`的直锁/实时坐标旁路，也不得让展示点击改变AI。枪声后端留待独立接入；可选枪械缺席时核心感知仍可运行。
