## 友善动物与中立生物

普通动物等友善/中立生物属于背景：它们走路、奔跑、游泳、落地及其他以自身为来源的普通声音，不会让人类警觉、转头或调查；看到它们也不主动累计敌对识别或锁定。它们在声音候选和声源采样前就被排除，避免大量动物占满近场候选及感知额度。玩家主动攻击这些生物时，士兵不跟随主动进攻。

分类使用原生敌对接口和实体类别：玩家、本模组人类、实现Enemy接口或注册为MONSTER类别的生物继续各自原有规则；其他普通生物按背景处理，不按中文名、模组名或单个动物ID写名单。因此狼、熊等中立动物平时也被忽略；未声明敌对接口/类别的模组生物初始同样按背景处理。

有两个防御例外：人类本人遭到真实直接伤害，或者既有保护逻辑收到动物攻击雇主的事件。例外只给对应生物记录有期限的防御来源，仍要目视确认，仍通过阵营、战斗模式、命令及安全约束；不是立即隔墙锁敌。保护雇主不会扩展“完全中立”等模式本来没有的保护许可。

尚未目视确认的防御来源记录默认沿用旧敌身份期限120秒；若已合法确认，则后续仍按30秒动态位置及120秒旧敌身份规则维持。期限失效后回到忽略状态，不会永久敌视整个动物种类。即便曾攻击过，普通脚步仍不用于反复刷新警觉或调查；后续反应来自实际受击、保护雇主或合法目视证据。动物、玩家和友军之间的物理碰撞、击退以及原版互动不由此取消。

这些规则无独立配置开关；防御来源的期限复用 `perception.memory.familiar_ticks`，不新增另一套永久白名单。声音预算见 知识库活动预算与调度，雇佣保护边界见 知识库雇佣士兵与命令名册。

## 视觉、移动与战斗如何交接

视觉识别、观察请求、主攻击目标与目标记忆是四个不同状态。最多两个目标独立累计目视证据；已确认目标分别保存动态期限。人类只集中攻击一个主目标，识别其他目标不暂停现有战斗，杀死主目标后直接从仍有动态位置且许可有效的记录中接替。

| 情境 | 身体与移动 | 头部与识别 |
|---|---|---|
| 普通导航、跟随、调查、追击 | 移动控制要求的方向决定身体朝向 | 默认单侧最多60°，并受实体原有上限限制；超出范围的观察请求不能拉转身体 |
| 闲置驻足 | 可以平滑转身观察 | 自然环顾和主识别请求提供看向位置 |
| 原地瞄准、实际近战出手、举盾或明确战术侧移 | 使用实际战斗动作的朝向规则 | 盾防、近战出手和射击请求优先于普通观察，不用头部请求冒充攻击方向 |
| 真实受击，但未在处理6格内已确认敌人 | 可以短暂暂停普通移动并回看来向，默认最多20tick，转到来向后提前结束 | 来袭观察可中断远处普通识别；未知来源仍需目视确认，不读取隐藏射手坐标 |
| 逃生、岩浆、爆炸等紧急情况 | 保留生存任务与路线 | 普通观察不能抢占；受击回看也不能阻止必要逃生 |

主目标选择由共同入口完成，贴身保护和增强战术只提供角色或压力建议。普通建议默认至少保持当前主目标20tick；已确认近处紧急威胁、原有拥挤压力判断与多来源集中处理可例外。原有60tick多来源压力窗口、80tick集中处理及近敌优先条件继续生效。驻守保留目标与返岗约束、主人攻击许可、阵营、和平和菜单/固定点测试等限制仍须分别通过，记忆不自动续攻击许可。

已确认目标的动态位置默认600tick（30秒）。目视或动态期内该来源真实直接伤害刷新其自己的期限；转头、切换主目标和识别其他敌人不删除记录。到期后冻结最后合法位置，保留600tick（30秒）的位置线索；旧敌身份默认2400tick（120秒）用于加快重认。声音、求援、信标及其他敌人的伤害均不能刷新动态期限。改变主人清理旧知识；普通行动命令改变取消旧动作和线索，但保留仍合法的身份记录，当前能否攻击重新按命令判断。

两个识别名额使用独立轮转游标，即使每轮只允许1个快速采样，也不会永远只检查第一个。已确认主目标定期取得复核机会；新增目标与主目标维护交错时，按该目标安排的检测周期累计证据。真实连续负检测达到40tick（2秒）清零，配额等待不算负检测或免费证据。真实受击可暂时让较远识别让出一个名额；被暂停的进度保留，恢复后继续需要实际有效目视。

配置入口：`global.json → perception`；`memory.dynamic_ticks=600`、`recognition.break_ticks=40`、`attention.moving_head_angle=60`、`attention.hit_response_ticks=20`、`selection.minimum_hold_ticks=20`。时间均为服务器tick（20tick约1秒），这是模组默认值；已有实例自定义值继续按其配置执行。

头盔分别显示主攻击目标、选择原因、两个识别对象及暂停进度、观察请求与实际朝向负责人、身体/头部角度、各目标动态剩余与攻击许可。几何视野按实际头部yaw与俯仰展示，不能把请求看向某处等同于已经实际朝向它。导航、身体与当前观察请求分别判断，实际射击仍须弹药、许可、朝向及射界通过。


## 自然环顾、稳定识别与墙后退避

自然环顾默认最多4°/tick，并按实际平静扫描间隔进一步限制：`最大扫角速度=min(配置速度,远段完整视角/(3×扫描间隔))`。因此人数多、检测变慢时，头部也不会在两次检测之间扫完整个远段视野。它限制无任务环顾，不延迟已明确执行的射击、近战或举盾朝向。

首次实际看到可疑生物的身体采样点后，会把已露出的部位作为主观察点，稳定继续识别；普通拾取观察和随机环顾不能覆盖这项请求。导航移动时仍以身体前进方向为准，头部受单侧60°上限约束；战斗中的实际瞄准和防御仍优先，不能为了发现新敌人拉转移动身体。

候选先进行距离与身体采样点的视野几何筛选，有至少一个采样点进入视野，才申请快速射线工作。正在等待的身体补查独立恢复，不依赖该目标仍留在当轮快速候选列表；同一tick已成功目视的目标不重复赠送识别进度。视野外是一次真实失视，预算等待仍是未知，两者不混淆。

只有实际检查完本轮有效身体采样点、并且全部被方块阻挡，才写入遮挡退避：默认10、20、40tick，随后最长仍为40tick。主体眼部或目标中心移动超过0.5格，身体尺寸变化，头部水平或俯仰变化超过8°，或已检测到的遮挡方块状态改变，会解除缓存。缓存有限容量且总会到期；不是永久屏蔽，也不能因一次预算不足就判断全身被挡。未记录的世界变化最迟由到期复查处理，不需要全地图监听。

| 配置 `perception` 下的路径 | 默认值 | 含义 |
|---|---:|---|
| `attention.idle_head_step` | 4°/tick | 自然环顾最大速度，慢扫描时进一步降低 |
| `attention.sound_glance_ticks` | 20tick | 战斗中重要声音辅助回看期限 |
| `vision.occlusion_retry_ticks` | 10tick | 首次完整遮挡后的退避 |
| `vision.occlusion_max_retry_ticks` | 40tick | 静止遮挡最大退避 |
| `vision.occlusion_move_reset` | 0.5格 | 主体或目标移动解锁阈值 |

远处主目标低于22分、距离超过6格时，附近优先级至少3的重要声音可提交20tick的静态地点回看请求。它不改变主攻击对象，也不下达移动路线；实际射击、近战、举盾、近处已确认战斗及逃生可压过它。听到背后玩家后仍需转入真实视野并完成识别，才能加入威胁评分。一次未移动线索不会每tick反复触发同样回看。

## 入口 → 条件 → 状态 → 消费

`Human`服务端tick推进`HumanPerception.tick`；声音适配、真实受击与主人事件请求观察或线索，只有共同边界能够把目视证据转为已确认目标。目标Selector、增强战术、护卫与武器执行不能仅因持有LivingEntity就取得合法实时位置。

| 责任 | 入口 | 必须保持的约束 |
|---|---|---|
| 参数 | `PerceptionConfig`、`UnifiedConfig.perception()` | 全局不可变配置快照，默认值、范围、说明集中；完整重启生效 |
| 时序与几何 | `PerceptionPolicy`、`RecognitionEvidence`、`BodyVisibilitySamples` | `now < until`才动态有效；伤害只续有效期；组合系数独立收敛；三个距离锚点间插值视角 |
| 视觉/识别与知识 | `HumanPerception.tick/check` | 敌我、同维度、范围、朝向、原版可见度、方块COLLIDER射线；预算不足不视为成功 |
| 攻击准入 | `HumanPerception.canTarget`、`Human.setTarget` | 已标记且动态有效，再复核存活、同盟、模式与命令；确认不代替许可 |
| 合法位置 | `HumanPerception.knownPosition` | 动态期内真实位置，到期只最后位置，不可把线索UUID解析为实时导航目标 |
| 受击与回看 | `HumanPerception.hurt/finishLook`、`HumanAttention / IncomingHitResponseGoal`、`AttentionFacingPolicy` | 弹丸方向快照、无可靠方向安全降级；真实受击可中断普通观察；多来袭短暂排队 |
| 声音/求援 | `HumanAwareness`、方块/通道Mixin、事件入口 | 点时线索、同源去重、有界排队；平静/警觉均监听脚步，线索LOOK独立于MOVE；友军求援不转交攻击者 |
| 调查移动 | `PerceptionInvestigationGoal`（旧调查Goal入口委托） | 只消费位置；复用BasicNavigationBudget、HumanTerrainSafety与RetreatPathSafety；仅停止自己拥有的路径 |
| 信标报告 | `BeaconReportingService`、`BeaconReportPolicy`、`HumanSignalItem` | 仅成功生成后used；同玩家/维度通道；周期/报告TTL/发报总期限分开 |
| 战术与动作 | `AdaptiveCombatGoal`、盾防/武器/护卫入口 | 继续现有威胁排序，所有目标/位置须共同准入；视觉仅提供证据/朝向请求，战斗与MOVE保留实际控制权 |
| 诊断 | `PerceptionDebugSnapshot/Codec`、`NavigationDebugService/Client`、`NavigationDebugViewPolicy` | 服务端只读快照，客户端只显示；分页/焦点切换不下达行为命令 |

识别默认公式为 `max(2, ceil(min(45, 5 + 0.625 × 距离) × 状态系数))` tick；警觉或旧敌单项0.5，组合0.4，受击来源快速识别2tick。

识别使用归一化证据量。只有实际检测发现出视野或遮挡，才开始连续失去视觉的计时；达到40tick清零。短暂遮挡保留已得进度但暂停累计。尚未轮到检测或预算不足只表示未知，不能当作已经被遮挡，也不补算等待期间的长时间证据。首次看见候选后改用活跃采样间隔（默认4tick），避免平静10tick间隔与中断阈值相撞。

每个人类最多同时推进两个目标的视觉识别，分别保存进度和遮挡起点；识别完成不等于能同时攻击两个目标。一个主识别对象提交辅助转头请求，移动和战斗保留实际朝向权；另一个目标只有仍在实际视场内且无遮挡才推进，不能为了同时识别去读背后或墙后的坐标。头盔显示“并行视觉识别 数量/2”以及各目标的进度和主观察归属。

陌生目标的默认完整视场角按三个人类眼部至检测点距离锚点确定：8格及以内160°、32格处120°、64格及更远90°；8～32格、32～64格之间线性过渡。例如20格140°，48格105°。这里是完整夹角，判断时换算为半角；近场体积采用水平角，柱体外的常规视觉才使用三维圆锥。旧敌默认半角乘1.2，最多90°，对应完整夹角近处180°、32格144°、64格108°；旧配置的上限也不能把旧敌视野缩得比陌生目标更小。几何视野仍须真正无遮挡，潜行/隐身的原版可见度修正仍适用。

识别证据按每次真实检测推进，不从预算等待时间补足。每人默认一轮最多2个快速候选，身体补查普通每批最多9条/目标且同占总池，平静10tick、活跃4tick；邻域查询、射线、线索投递和移动声源分别受每维度及全服务器配额限制。默认每维度/服务器每tick为查询64/128、射线128/256、线索256/512、声源128/256；事件查询最多占25%。这些仅约束新增感知工作量，不涵盖原有战斗、寻路等所有查询；不是公平延迟或毫秒性能保证。

身体可见性不再要求露出眼睛。先检查上次可见部位（没有记录时先看眼部），不通时补查逻辑包围盒的3×3×3采样点，覆盖躯干中心、上下/左右表面、边心及角点；任何采样点在有效距离和视场内、且人类眼部到该点无遮挡，就在本次采样开始或继续识别，不必等待头部露出。主观察注视已露出的部位；下一次优先复查该部位，并随实体位置/姿态的包围盒变化更新。

这不是立即激起仇恨：仍需累计识别进度，仍检查关系/攻击许可。平静检测默认每10tick，识别中每4tick；候选轮转和总配额可能带来调度等待。采样依据逻辑碰撞体，不能保证命中任意细小缝隙或碰撞体外的模型、武器、装饰像素。视觉发现也不替代实际射击弹道/命中检查。

每人每轮默认最多检测2个快速候选。快速部位不通时，`perception.budgets.body_rays_per_target`默认允许该目标每批补查最多9条射线（可配置范围1～27）；发现可见点立即停止。快速与补查共同受每维度128/全服务器256条每tick的原射线池约束，配额按保守申请量扣占，不是无上限追加。补查用完便取消下轮预留；未拿到配额不记为遮挡，低配额只完成部分点时轮转补点，不把尚未检查的身体判为全遮挡。

近距离不再只靠以眼睛为顶点的视锥。近场采用身体中心轴上的前向圆柱扇区：默认水平半径8格，陌生目标水平完整夹角160°，旧敌默认扩展到180°；高度从人类身体包围盒底部向下1格，到身体顶部向上1格。水平朝向跟随头部yaw，整个柱体不随抬头或低头倾斜，脚下正中没有水平角度盲点，因此低矮生物不必先靠低头才进入几何范围。

柱体高度与水平半径内使用水平夹角判断，不再以三维锥角把脚下排除。柱体之外保留原有三维视锥，避免丢失主动抬头看高处等能力；中远距离仍按原有角度锚点逐渐收窄。近场不是全向感知，陌生目标背后仍不属于该扇区。任何身体采样点都必须继续满足实际视觉距离、原版可见度和从眼部出发的方块遮挡检查，地板/墙壁不会因为近场体积而被看穿。

配置为全局`perception.vision.near_distance`（水平半径及视角过渡锚点，默认8）、`near_full_angle`（水平完整夹角160°）、`near_below_feet`与`near_above_head`（默认各1，范围0～16）。高度基于当前身体包围盒，随姿态变化；新旧目标共用高度与半径，旧敌仅扩大水平角。

## 状态归属与保存

`HumanPerception`逐实体弱引用状态包含独立目标Track（确认、动态/最后/旧敌期限、归一化进度、独立RecognitionEvidence）、线索、待观察来源、LOOK归属和有限转换记录。目标死亡、无效、关系变化与过期在服务器维护；主人变更清掉旧知识；行动命令变更取消旧观察和攻击动作，保留合法身份记录。普通感知不写NBT，卸载不恢复未完成识别。

`BeaconReportingService.Store`通过主世界SavedData保存通道，键为玩家UUID与使用维度；保存最后成功使用、总截止、下次发报、报告序列、采样时刻、报告截止和网格坐标。成员NBT存追捕玩家与使用维度，旧实体有追捕UUID时以当前维度补兼容身份；接收去重是临时状态。使用全服主世界游戏时钟，重载只恢复剩余期限，不重新起算。招募或有效主人出现时删除实际追捕目标，出生来源标记的掉落语义另留原处。

## 同步与诊断

只有有效观察者才生成并发送有界快照，默认5tick间隔，最多8个人类。导航通道协议5的帧携带同实体的感知快照，客户端3秒没有新帧时隐藏旧数据；目标身份/位置按知识阶段裁剪，未知方向不发送隐藏射手身份坐标。每页只筛选已收到字段，不为了展开详情重扫实体、补射线或重算路径。最近状态转换最多32条/20秒；感知射线只显示近期已有样本，几何视锥与真实无遮挡证据分别渲染。调试快照与观察选择不作为持久AI状态。通道5保留唯一空负载C2S焦点轮换请求，服务器检查头盔、权限和自己的当前维度观察会话；快照仍仅S2C。

F8六页为概览、目标/记忆、视野、声音/信标、动作/导航、预算，可选择世界标记层与焦点。动作页读GoalSelector实际运行集合、priority、控制标志及手部占用，并显示战术压力/记忆数量与锁定剩余，决策意图不能代替当前MOVE/LOOK任务；固定点测试暂停自主观察并明确显示接管。

平静和警觉的人类都能接收附近玩家、人类及敌对生物的合规脚步/奔跑落地/水声；普通友善/中立生物在采样、事件排队和接收前过滤。声音先产生位置线索和警觉，随后可以转向声源当时的位置；不会凭声音确认敌对身份或直接锁定，也不会在声源停止后继续读取其隐藏实时位置。

转头独立于调查移动：原地驻守也能回头观察，但仍不离岗。新线索或线索位置移动超过2格时请求短暂注视，默认最多40tick（2秒），不同线索的回看至少间隔20tick（1秒）；同一固定位置不会每tick重复抢头。调查移动中的观察可以持续到该任务结束。真实受击回看、当前战斗目标、撤退以及睡眠/NoAI/固定点测试优先；是否走过去继续由原命令与安全路径决定。

脚步是服务端模拟：需要真实累计位移（普通0.8格、奔跑0.6格、游泳1格），初次采样先建立位置基线，平静邻域默认10tick、活跃4tick，另受声源冷却与全局配额约束。因此不是任意音效播放即触发。默认仍忽略本人、已知友军普通脚步、潜行/无声、创造/旁观玩家，以及受击位移/超过8格的传送跳变；枪声后端仍未接入。

受击先产生真实来向观察请求，由朝向边界落实。普通行走保留移动身体方向，头部在允许夹角内观察；必要自卫可短暂停步回看，不能抢占逃生或正在处理的近处已确认威胁。弹丸仍只使用可靠来向，未确认者必须目视，驻守回看不会走出岗位。

没有合法攻击对象也可以回看可靠来袭方向，但不授予攻击许可、不读取未知射手坐标。真实受击可以中断普通远处观察；正在进行的短暂来袭回看对其他来源保留排队，避免连续抖头。没有可靠方向的未知弹丸只警觉，持续伤害不伪造新方向，取消或免疫的伤害不计真实命中。

## 失败路径与修改约束

- 敌我或主人许可过期：清目标/拒绝攻击，知识不自动续权；位置调查仍单独受命令约束。
- 未知弹丸无有效速度、无可靠来源或周期伤害：保留警觉，不补出隐藏射手位置。
- 识别遮挡10tick、方向2秒、识别任务6秒：释放占用，后续排队来源才有机会处理；不借重复伤害无限延长本次占用。
- 动态截止tick起：伤害不能复活实时位置；回看方向后依实际目视恢复。其他目标不联动续期。
- 查询/射线/导航配额不足：等待，不记为检测成功、识别完成或路线不可达。
- 无安全落点、区块未加载、命令不允许或路线不可达：有限重试并结束；不强加载、不传送、不拆墙，也不停止另一控制器的路线。
- 信标无有效通道/玩家离线或跨维度/成员受控/超范围：不接收报告；观察详情只读，不创建通道、发报或清理存档。

扩展新事件应先回答它提供的是许可、方向、静态位置还是合法动态知识，再接共同入口。不得新增绕过`canTarget/knownPosition`的直锁/实时坐标旁路，也不得让展示点击改变AI。枪声后端留待独立接入；可选枪械缺席时核心感知仍可运行。

## 候选、识别证据与调查的调度边界

视觉邻域查询遍历已加载范围中的活体，先判断敌对许可，再用固定容量保留候选；默认16个名额，一半优先最近敌人，其余按随轮次变化的UUID次序补充。动物或友军不能占满敌方候选名单。脚步另留最多64个近场声源名额，并按轮次轮换；超密集场景仍会延迟发现，不保证每轮遍历到的所有敌人都做射线检测。

识别证据与动作控制分开。120tick只限制一次普通主观察请求，不占用战斗LOOK。实际可见证据保留，只有真实持续负检测达到40tick或实体失效等条件才中断。主目标维护与双识别交错，低配额会延长实际发现时间。

身体补查分批执行时，记录本轮有效身体采样点的身份及已测部位。只有当前有效部位都已检查且均被遮挡，才报告一次完整负检测；任一部位可见或有效采样集合改变会重置旧覆盖。默认27点仍是有限的逻辑包围盒采样，不能保证看到任何渲染像素或任意细缝。

事件投递、视觉候选和玩家局部人数检查使用不同工作标识，共享原来的查询总池；拆分入口不会增加总额度。成功的一次性工作不再预留下一tick；失败请求保留排队优先权。查询预算按查询次数记账，不是CPU毫秒或遍历实体数的硬上限，密集实体区域需另行测试。

求援和爆炸优先于普通声音投递，使用自己的有效期限，不受普通声音默认10tick的排队期限截断；事件队列仍最多512条，极端拥堵不能保证全部交付。声音位置短时间往返时采用最新位置，不再延迟提交中间的过时坐标。

调查被识别观察、避险或其他移动任务打断时暂停，在线索仍有效且命令允许时可以恢复。每条线索累计搜索时间与已完成搜索点，达到时长、点数、重试上限或线索到期才结束；纯等待路径预算不消耗有效搜索时间，但声音线索自己的绝对到期仍照常推进。调查只停止自己持有的路径，不能清掉后续战斗或命令的新路径。

## 评分与预算接入

`HumanThreatAssessment`先通过canTarget才读有界生命/护甲/攻击属性与远程能力，属性快照按动态档位刷新；`ThreatScorePolicy`结合距离、80tick实际伤害和原生攻击意图评分。`HumanTargetCoordinator`保留保镖职责、最短保持及25%且5分切换余量；6格内较强目标可打破22分以下远敌偏好。候选、提案与压力锁共同经过selectionAllowed，不能绕过玩家围攻人数限制；同tick复用准入检查结果。Adaptive私有压力锁服从共同锁释放。

`activity_budget`统计全服最近60tick人类心跳，每20tick采样，16/64/128分档，降档保持100tick。动态容量只影响下一tick，保留公平队列和硬上限；紧急/连续性池保持。围攻判断复用合法动态记忆，不再重复进行世界实体扫描。头盔展示最近评分/档位/声音分级/视觉预筛，不额外发起计算。
