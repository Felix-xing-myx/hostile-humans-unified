# 背盾显示资源配置

持枪时的副手盾牌由统一客户端入口显示在背部。未知盾牌默认复用自身第三人称手持模型和原生渲染器；不能保证任意自定义模型都自动正确，但调整不再需要新增 Java 模组分支。

资源包路径：`assets/<资源包命名空间>/back_shields/<任意名称>.json`。支持 F3+T 重载，无需服务器安装。覆盖内置规则时使用相同资源路径；新增规则可使用其他名称。内置三个配置位于 `assets/hostile_humans_unified/back_shields/`，分别处理原版盾、斯巴达实体盾和普通烘焙盾。它们替代此前硬编码修正。

```json
{
  "item": "example:shield",
  "priority": 10,
  "mode": "back",
  "context": "third_person",
  "translation": [0, 0, 0],
  "rotation": [0, 0, 0],
  "scale": [1, 1, 1]
}
```

- `item`：可选，精确物品 ID。`namespace`：可选，匹配整个模组命名空间。两者同时填写时必须同时满足。省略两者表示所有盾牌。
- `custom_renderer`：可选布尔值，匹配当前资源模型是否使用自定义渲染器，仅用于筛选；不据此自动猜测模型朝向。
- `priority`：默认0，越高优先。相同优先级精确物品优先于命名空间；同类规则附带模型筛选者优先；最后按资源 ID 字典序选第一条。
- `mode`：`back` 默认背负；`offhand` 直接回到原副手渲染路径，其他变换不生效。
- `context`：`third_person` 默认，沿用原生左右手显示变换；`none` 用于已明确其模型坐标的特殊盾牌。
- `translation`：在躯干背负锚点与倾斜之后的位置修正，单位为方块；模型局部Y正方向随人形模型朝下。默认零。
- `rotation`：局部X、Y、Z顺序，单位度；默认零。正反面通过Y旋转等变换调整。
- `scale`：三轴缩放，必须为有限正数；默认1。

操作顺序：躯干姿态 → 背部锚点（鞘翅时后移）→ 左右手对应25度倾角 → 数据平移 → XYZ旋转 → 缩放 → 原生手持变换（third_person时）→ 原生物品渲染。原版与斯巴达实体盾的数据平移已换算到旋转前坐标，与旧中心补偿等价。

非法配置记录警告并跳过，其他配置继续加载；删除规则后恢复下一条匹配规则或默认姿态。资源包仅影响客户端显示，不会更改库存、防御、减伤、耐久或枪械判断。TaCZ与焦燃共用入口，无需两种枪械模组同时安装。

验收：原版盾正反面；斯巴达基础盾/塔盾位置；未知盾牌默认姿态与offhand回退；资源包覆盖及F3+T增删；左右手、蹲伏、鞘翅、旗帜与附魔。源码静态检查不等于视觉验收。
