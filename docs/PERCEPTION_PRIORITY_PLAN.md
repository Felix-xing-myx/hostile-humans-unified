# 感知负载、声音分级与主目标决策整改方案

把声音、视觉作为有优先级的证据输入，已确认目标由统一威胁评分选择；动态活动预算只调整可延后的工作密度，不削弱真实受击、生命安全或正在执行的攻击。基线eedc9fc，前项未构建源码保留。本文件是实施/验证计划，当前机制以实现和知识库机制正文为准。

## 范围

覆盖听觉输入、视觉候选与转头、遮挡退避、逐目标威胁评分、动态感知/导航活动预算及头盔诊断；不增加墙后视觉授权、声源实时追踪、全局扫描、客户端决策、线程寻路或枪械内部API依赖。

## 有序实施

1. 核对输入到notice/识别/选敌/朝向/导航的真实入口，逐项登记旧冲突；所有共享文件由主控接入。
2. 增加声音来源和事件重要性：受击/友军求援最高，玩家活动高，主动攻击人类/雇主的怪物高，普通未交战怪物脚步背景级；加高差/距离/遮挡衰减、重复背景线索节流，声音仍只提供静态线索。
3. 增加全服人类心跳统计与带滞回的稀疏/普通/拥挤/团战档位；单人感知份额、扫描间隔、身体补查、声源采样与可选导航吞吐动态变化，保留全服硬上限、FIFO和紧急池。
4. 统一已确认目标评分：基础血量/护甲/攻击属性/远程能力有界归一，结合距离与近期真实伤害；保留角色职责、攻击许可、主目标最短保持与切换差，近处威胁可打破远处低威胁保持/压力偏好。未确认声源只促使安全回看，不能成为攻击对象。
5. 修复远距扫过：空闲自然转头限速，首个真实可见可疑目标优先进入稳定主观察；候选在申请射线前过滤视野几何，保留近场发现名额，战斗/导航身体仍优先，不冻结移动。
6. 缓存完整遮挡负结果：只有实际完整采样否定才退避，按次数有限延长，主体/目标位移或局部方块变化解除；低配额部分采样仍续游标，不能误记不可见，不把缓存当永久黑名单。
7. 同步头盔声音重要性/档位与数量/候选跳过原因/威胁分与切换理由；先备份后同步知识库机制正文、参数表、修改入口和相关方案。
8. 增加纯策略及接入回归，执行Java17 build lootScreeningTest与适当全回归、资源/可选依赖/包审查；问题修正后核对版本日志，确认实例停止、备份、留存dist、同步并核对三方SHA，最后本地整合。游戏由用户验收，不擅自启动或终止。

## 关键决策与初始参数

- 统计最近60tick有心跳的加载人类，20tick重采样；16以内稀疏、64起拥挤、128起团战；降档保持100tick，上档及时响应。数值统一可配置并记录。
- 稀疏感知扫描间隔约减半、快速候选探测翻倍；拥挤/团战分别延后低优先扫描，身体补查分批缩到5/3，不减少身份记忆有效期。真实受击来源不因低档丢失。
- 原Basic/Optional战斗等可延后导航工作在拥挤/团战缩至约1/2、1/4，最低能容纳完整请求；紧急/连续性/已安装路线执行保持。预算切换不能重建队列丢位置或重新发放本tick已消费额度。
- 属性威胁只读已确认实体；最近80tick真实损血加入动态压力。低风险远敌不能压住6格内已确认近敌或近处重要回看。没有目视确认时不以评分越过发现规则。
- 背景怪物脚步默认不启动调查，近处无遮蔽的危险例外可升级；动物本人受击/保护雇主例外保持。厚墙与高差削弱可听范围，不模拟无限穿墙雷达。
- 转头速度按无任务自然环顾与真实观察区别设置；稳定观察仍需持续LOS，失去视觉按原中断规则处理，移动身体沿导航。

## 必须验证的边界

平静人类墙后地牢/脚下洞穴；近处玩家与背景怪同声；主人受袭/动物保护；近敌背后脚步与远处低威胁目标；高伤远射手；双目标识别与主目标死亡接替；64格目标短暂进入FOV；身形小/局部暴露；不可见缓存后目标绕出墙/方块拆除；1/16/64/128人负载切换与队列公平；低自定义预算/跨维度；头盔权限及无观察不额外计算；武器侧移、导航、避险与可选模组缺席。
