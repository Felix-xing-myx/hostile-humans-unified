## 已核查的外部做法

- [Linux 实时调度队列](https://github.com/torvalds/linux/blob/master/kernel/sched/rt.c)采用每优先级一条队列。听觉只有五个固定等级，直接按等级分队即可，入队无需搬移积压，取最高等级最多检查五条队列。512 条总容量、同等级先入先出、满时淘汰最低等级尾部及处理进度均保留。
- [Unreal Animation Budget Allocator](https://dev.epicgames.com/documentation/unreal-engine/animation-budget-allocator-in-unreal-engine)用画面重要程度动态调整动画更新。与现有距离/人数分档同方向，是否引入帧耗时反馈需先检查当前分档的成本和兼容动画状态。
- [Valve Source NPC 小队策略槽](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/server/ai_basenpc.cpp)通过释放可占用槽位协调共享目标。HHU 已有拾取目标占位，战斗中能否借鉴需先区分开火资格、选敌及移动位置争用。

- [Linux 调度带宽回收](https://docs.kernel.org/6.13/scheduler/sched-deadline.html)区分实际执行和可回收的预算。HHU 在 FairWorkBudget 内退回明确取消或实际未使用的预约余额。既有阵营轮转、每 tick 上限和已执行计数保留。未调用取消的离场请求仍依赖既有过期机制。

- 感知队列核对了维度与全服原子预约，以及饱和维度不会阻塞其他维度。沿用导航轮的预算回收原则，取消、缩小和无效预约均按原维度归还未使用余额，同时归还全服额度。需求所属阵营与批次规则沿用现有调度。

## 战斗动作权限

- HumanBehaviorControl 在多个同 tick 入口推进时钟。ActionCoordinator 每个时钟值只执行一次到期扫描，直接通过迭代器移除到期动作。正常取得空闲资源时无需创建抢占清单。
- 抢占仍先验证整组资源，失败时保留所有旧所有者。会话关闭先禁止准入，再执行实际移动、枪械、恢复等清理，最终取消旧令牌。权限回收与物理动作收尾是两层职责。

- 恢复按真实消耗回执结算，并在原版停止用物回调前撤销会话。枪械会话取消沿真实手部与背包堆栈逐项委派给联动适配器。修复其中一把武器的适配器抛出运行时异常时，其余枪械无法获得取消通知的问题；本地托管与战术状态在 finally 中收尾。联动异常下该适配器自身内部状态仍需由其实现处理。
- 枪械清理采用与 [Java 资源清理规范](https://docs.oracle.com/javase/specs/jls/se17/html/jls-14.html#jls-14.20.3) 相同的异常保留原则。各武器独立尝试，首个运行时异常在本地清理后上报，其余附在首个异常下。

## 监控退出

- 已追踪主动退出、切换、目标离场、断线及停服到服务端会话关闭。关闭时先撤销会话，再逐项释放远程视点、接管、背包和客户端显示。某个运行时异常不应跳过其他步骤。接管战斗清理异常时仍清空移动输入。渲染、UI 和远程音频待深入。

## 建筑模板

- 导出先在同目录写完整临时 NBT。覆盖要求原子移动，失败返回错误，新建不覆盖已有文件。缓存仅在提交后失效。
- 放置前保护既有建筑信息方块，原实现最多逐格检查 262144 次。现复用原版已加载区块的方块实体位置索引，包含待加载数据，只对实际落在模板范围内的候选核查类型。预览几何、注册和存档格式沿用现有接口。

## 经济库存事务

- 钱包及实物提交先在副本上计算，再校验真实槽位。账本保存 PREPARED 并调用库存提交，之后推进政治状态和回执。发现 Curios 等槽位写入抛错时旧回滚会改写尚未触及的槽位，且单槽回滚异常会中止其他恢复。现按实际尝试过的写入逆序恢复，校验恢复值并保留失败项供账本重试。进程崩溃后的日志恢复及培养事务待单独核查。

- 经济重启恢复增加前序凭证检查。库存摘要可以在不同交易后碰巧相同，只能证明当前库存内容。比较 [SQLite 原子提交](https://www.sqlite.org/atomiccommit.html) 的跨文件协调机制后，保留 Minecraft 存档格式和保守恢复路径。Minecraft 的多个存档文件依然独立落盘。

## 客户端人类渲染

- 视图分档使用上一帧绘制数量及相机距离，摄像机目标、手臂和容器预览保留完整呈现。共享模型每次恢复初始姿势与动画绑定，避免上一实体姿势泄漏。
- 同一绘制入口复用一次举盾手判断，常规手持物不再进入可选枪械识别，只在原生充能弩姿态可能与枪械姿态冲突时核查。沿用现有远近分档和联动动画优先级。后续须用游戏内帧时间判断引入动态预算的收益。

## 网络输入检查

- 按 [Forge SimpleImpl](https://docs.minecraftforge.net/en/1.20.x/networking/simpleimpl/#handling-packets) 核对服务端主线程、消息方向和客户端坐标的已加载区块检查。已确认作者编辑器、模板放置和选区绑定使用服务端权限。补齐框选棒直接点击的区块检查。
- 属性详情的客户端打开请求改为在实体查找前限流，实体 ID 与 UUID 匹配后再走共用权限和快照入口。监控控制包已有有限浮点、世代和序号校验，其他联动和注入仍待核查。
