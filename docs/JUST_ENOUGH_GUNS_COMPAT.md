# Just Enough Guns 联动

## 范围与配置

JEG独立安装即可联动，无需焦燃。支持实弹、幽灵弹、烈焰弹、声波、共振、喷火、枪射榴弹/火箭及水系战斗武器；提供的JEG枪械数据中有31把对应战斗枪械。按原生弹种能力接入，同类新增枪不依赖逐把枪名硬编码。弓和采集工具不作为枪械；圣经、手指枪、信号枪等治疗/玩具/信号功能物品不作为士兵攻击枪械。
| 枪械分组 | 额外支持的枪械 |
|---|---|
| 幽灵与烈焰弹 | blossom_rifle、holy_shotgun、hollenfire_mk2、soulhunter_mk2 |
| 声波与共振 | subsonic_rifle、supersonic_shotgun、hypersonic_cannon |
| 火焰 | flamethrower |
| 枪射爆炸物 | grenade_launcher、rocket_launcher |
| 水系 | atlantean_spear、typhoonee |

这些枪可交给已雇佣士兵使用；默认自然生成仍使用原有精选白名单，不自动把所有特殊武器加入出生池。全局黑名单仍有最高优先级。


JEG和焦燃共用全局及分阶 `scguns` 配置区，运行后端各自独立，目录不会相互覆盖。全局/分阶白名单来源、空表自动收录、高优先级黑名单沿用现有规则；名单用完整 `jeg:` 或 `scguns:` ID。已有自定义名单不追加默认枪械。新配置提供分阶精选JEG枪池；雇佣士兵可用所有已接入战斗枪械，仍受黑名单限制。

JEG没有公开武器类别字段；全局 `scguns.jeg_gun_types` 按注册ID定义类别，未知合格战斗枪默认rifle。类别只决定通用弹匣计费，不会开放治疗、玩具与信号功能物品。默认手枪/冲锋枪1、步枪/霰弹枪2、狙击枪3、机枪4；修改 `scguns.magazines_per_reload_by_type` 可调整。

## 战斗与换弹

通过公开 `AIGunEvent.performGunAttack` 生成原生子弹并保留配件、附魔和武器弹丸属性，复用 `GunnerGoal`，不新增移动控制器。清障检测与瞄准考虑JEG原生水平发射点偏移。枪械有效射程受原生修正弹速×修正寿命减1格限制；优势距离不超过该射程的85%，避免短寿命声波或火焰在远处空射。带原生fireTimer的武器先完成预热，再发射；丢失目标、换枪或中止瞄准会取消预热，不凭空扣弹。

人类枪伤＝原生武器命中伤害 × 全局 `scguns.human_gun_damage_multiplier` × 本阶 `scguns.damage_multiplier` × 战斗经验枪伤系数。默认全局0.7、分阶1；成长阶段不减枪伤，低于100%战斗经验不减枪伤。仅解除本模组人类子弹的原生NPC难度减伤和命中玩家的难度缩放，不改变原生怪物或玩家枪伤。原生目标分类、防具、抗性等仍参与结算。爆炸和水系区域伤害也保留原生伤害类型、归属、全局倍率与经验增伤；持续燃烧、共振及其他后续状态效果沿用原生效果规则。

JEG原生散布乘以战斗经验散布系数，再除以 `scguns.ai_accuracy_modifier`；不叠加TaCZ的分类散布。散布本身仍来自JEG武器、配件及原生难度规则。

换弹读取公开原生装填类型、时间、附魔和弹量修正；不伪造Player、不调用玩家库存。整匣式按原生间隔填满，逐发式按原生检查节奏分步补弹，一轮装填仅扣一次通用弹匣。库存供弹型实弹枪使用士兵专用虚拟弹仓，默认100发；全局`scguns.jeg_inventory_fed_capacity`可改为1–4096。打空后按武器类别扣一次通用弹匣、按原生间隔装满；原生AmmoCount保持原生容量内，不改变玩家的背包供弹机制。没有通用弹匣时换备用武器；全局关闭弹药消耗时免扣通用弹匣。后台换弹只在士兵仍持有原枪时推进，丢出枪械不会免费装填。

## AI所有权与手持投掷物

人类仅使用HHU的枪手控制器。JEG原生对持枪生物追加的GunAttackGoal、随机掷弹手标记、自动配枪及随从视野修改不接管本模组人类；JEG自己的生物保持原规则。即使外部代码给人类附加了原生枪手Goal，该Goal也不能运行，避免绕过弹药消耗、换弹时长和移动控制。

士兵禁用JEG原生无需库存的自动掷弹，只通过统一战术入口投掷真实库存。手榴弹和水炸弹默认加入各阶战术池，各权重3；燃烧瓶、烟雾弹、震撼弹可手动交付使用，不自然发放。爆炸装药暂不支持。与焦燃共用全局 `scguns.throwables` 使用名单、品质、轨迹、安全预检和冷却，不新增第二套AI。投射物成功加入世界后扣除一件，失败不扣；关闭枪械弹药消耗也不会免除投掷物消耗。枪射榴弹、火箭仍走枪械弹仓规则。

两种JEG出生投掷物与原有战术药水、焦燃投掷物共用本阶 `potions.tactical.pool` 和总数。仅完整匹配原默认列表时补入新默认项，玩家自定义或空列表保持原样；未安装对应模组时跳过不可用候选。JEG水炸弹保留人类投掷者归属，以接续友军过滤。烟雾、火焰和震撼效果仍由原模组处理；落点预检不能保证友军之后进入持续区域仍安全。

## 渲染与保护

公开LivingEntity绘制入口负责实际NPC持枪模型、配件和附着枪口效果，姿势从公开握持元数据读取，统一右手视觉；原生 `mini_gun` 握持类型使用JEG机枪姿势数据，按瞄准俯仰插值双臂角度、手臂挂点和枪体修正，同时采用原生侧身肩位，护甲袖层随手臂同步；普通单双手枪保留各自姿势。公开音效包播放枪声和装填声。不读取本地玩家开火状态来决定NPC火光。原生绘制失败时回退普通物品绘制。

枪射爆炸在Forge爆炸实体列表中按明确射手过滤友军；水花/水泡在施加伤害、减速或骑乘控制前过滤友军，保留雇主与PVP规则。水花伤害补回人类射手归属，同时保留原生DamageType，使枪伤倍率和战斗培养能够正确识别。

JEG弹丸直接继承Entity，未使用原版Projectile碰撞判断；通过严格限定的候选过滤接入统一阵营/雇主保护，先过滤再碰撞。保留同阶野生与已雇佣人类敌对规则、雇主保护及PVP权限。JEG原生对同实体类型NPC的90%随机免伤仅在人类射手下撤除，改由明确阵营关系判断；不会让敌对的同阶人类错误免疫彼此子弹。

## 维护边界

以提供的0.14.5版本核对公开接口。核心代码不暴露JEG类，可选实现按安装状态加载。仅原生NPC难度减伤、候选实体查询和NPC火光条件需要窄范围Mixin；关键保护与计费不可静默跳过。`tools/audit_jeg_compatibility.py`核对实际JAR公开入口及注入次数，不加载游戏。

扩展枪械已完成Java17构建、自动化检查及Forge47.4.21测试实例JAR同步。未改写实例自定义配置，游戏内行为尚待用户验收。后续重点测试JEG单独安装、与焦燃/TaCZ同时安装、逐发换弹、库存供弹武器、左撇子渲染、盾牌及友军穿透。
