## 主要修复及边界

- 移除旧 `MessageCommandHuman`、`HumanCommand` 及 `handleCommand/sit/follow/pet`。当前面板与名册已有服务端权威入口，旧入口没有现行调用者，却可以改变另一套 sitting/aggression 状态及无消耗回血。已有士兵的命令、锚点和巡逻点保留，加载/改令时清除旧坐姿。基础同步通道协议改为6，其余独立通道格式未改。
- 恢复交换槽保护覆盖自动弹药武器选择、枪/弓近战选择、装备优化、主手补位、通用存储及自动腾槽。结算只寻找真实物品；不能移动手中余物时停止覆盖。保护库存槽不等于禁止战斗、移动或并行进食。
- 防御期间的距离预测与出伤许可分开，避免举盾导致不断追近和无法进入正常反击窗口。水中移动与近战武器持有判断同样按武器身份处理，不能由暂时的出伤门禁取消。
- 远程寻找射击位置与其他战斗绕路共用整条路径的命令约束，增量规划返回前再次核验；保留原命令允许的追击例外。
- Better Combat快照包含序号、开始tick、动画、时长与前摇比例。视觉窗口为两倍冷却加2tick，与临时近战持有预算共用定义；播放器可自然提前结束。迟到补帧最多200tick，超限回退闲置姿势。上游按partialTick切换变速，整数补帧在边界可能相差1tick，不承诺任意帧率逐帧一致。
- 仅实际可播放的自定义攻击抑制原版挥手；动画失败保留回退，资源重载清理播放与能力缓存。实体数据布局和基础通道协议发生变化，客户端/服务器应使用同一构建。
