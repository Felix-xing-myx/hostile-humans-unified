- 主控行为框架：behavior-control-full工作树；所有共享Human/AdaptiveCombatGoal/UnifiedConfig/恢复/盾/武器接入由主控负责。

- main原有7项未提交修改保留备份；工作树没有自动包含它们，整合不得覆盖或自动提交。
- 现有搜索/感知/不可达区域排除保留。美术、农耕、砍树、社会模拟、新建筑和深度导航替换不纳入。

## 当前完成证据与边界

- 原生GoalSelector保留优先级、Flag与选取规则；HumanGoalExecutionBridge只把实际执行绑定到统一权限。HumanNavigationOwnership及直接输入通道保证原路线/原令牌清理，不另设第二个移动裁决者。
- ActionCoordinator统一原子准入、稳定令牌、暂停释放、重新准入、超时、取消及有界反馈；暂停不冻结硬期限，执行心跳只由真实执行刷新。旧会话或已终止令牌不能复用。
- HumanBehaviorControl.actions/peekActions/beforeTick/interruptMovement/cancel是共享会话边界：观察只读；命令只中断移动；完整切换先关闭准入并尝试全部清理，再废弃旧会话。未来中枢保存任务意图，恢复后重新申请权限，不恢复旧物理操作。当前固定战斗中枢，不实现农耕/砍树或跨中枢调度。
- CombatStrategySet集中阵营组合，真实物品和后端能力在执行前复查；GunPositioning、RangedMovementDecision只产生意图，枪/弓/弩/三叉戟执行模块保留原射击、路径、预算与地形规则。恢复、投掷、装填、防御共用权限与实物交换入口，各自持有真实进度和冷却。
