# 举盾防御维护入口

`ShieldDefenseController`是每个人类共用的举盾策略入口，由`Human.humanGunner$shieldDefense()`延迟创建。不新增Goal、世界扫描任务或静态实体缓存。

当前源码默认：真正举盾挡住TaCZ子弹时，`tacz.shield_damage_multiplier=0.4`，保留40%伤害、减伤60%。它不改变主手持枪＋副手盾的20%被动减伤；两者的装备条件不同。本次仅更新默认资源与缺项回退，已有显式配置不自动改写；2026-10-11本项待构建、待同步、待游戏验收。

## 调用关系

- AdaptiveCombatGoal：调用findIncomingArrow/wantsCombat、beginCombat/tickCombat/maintainCombat/endCombat。保留阶段调度、地形导航和实际反击。
- BodyguardMovementGoal：调用tickBodyguard/endBodyguard，保留不赋予攻击目标的贴身挡护与站位导航。
- HumanGunner：使用Forge ShieldBlockEvent及已有LivingHurtEvent向控制模块提供格挡/受击反馈，不修改事件伤害或取消状态。
- TaCZ：近战/弓弩主动盾沿用减伤与耐久入口；主手持枪时禁止主动格挡，改用独立副手盾被动减伤。
- RecoverySupplies：仅归还和选用盾，不再提交独立重举请求。恢复托管结束且有手持盾时，由统一战斗入口重新判断当前威胁。普通食物/金苹果由OffhandFoodUse独立推进，不占主手原生使用状态；临时副手食物仍会腾开真实副手盾，药水和医疗品继续使用原生恢复会话。
- Human：保留原生使用物品、移动惩罚、破盾冷却、朝向与同步。收盾核验来源以及正在使用的实际ItemStack。

## 近战决策

有攻击意图、朝向和视线符合要求、距离不超过3.5格的近战敌人可以触发提前防御；3格内不要求对方已经挥手或仍在移动。受击与提前预判共用该判断，不再依阶级或随机抽签决定近处防御。

有效举盾至少经过6 tick后，观察到挡住攻击且无预计命中的箭时允许反击；没有等到攻击时，最多20 tick开放攻击窗口。持续近战意图不会被短暂无受伤直接清除；敌人退出危险距离或转身离开可提前让位于追击。防御结束至少保留10 tick反击时间，弩手仍保留24/32 tick装填/预测防御窗口；已提交近战前摇不被重新举盾抢断。低血量恢复、士兵攻击许可与救主苦力怕例外保持。

## 持续枪火、防卫装填与后台换弹

近战与弓弩单位遭受TaCZ枪火时进入持续防御，不套用近战20 tick最长等待：每次新枪击刷新压力，最后一次枪击超过6 tick（约0.3秒）视为中断，收盾开放反击。新枪火可以中断普通反击窗口，但不抢断已提交近战前摇或恢复用品。防御期间近战继续接近，远程按既有射程调整位置；寻路失败不代表枪火结束。持续防御仍检查既有低血量撤退条件，撤退时取消主动举盾以释放移动惩罚。

原版一次只能使用一个物品。弓停止拉弦后举盾，收盾后重新拉弦；弩在副手盾使用期间，服务器累计真实主手弩的装填进度，再调用CrossbowItem.releaseUsing及现有NPC装填标记。沿用轻/重弩装填速度；实际齐射才扣背包通用箭矢，不创建第二套弹药或提前射击。更换武器、收盾、撤退及缺箭会清除未完成的防御装填；装好的弩保留已装填状态，交还原弩Goal射击。

主手物理枪械身份禁止所有主动举盾入口，包括护卫挡护；主手枪＋副手可用盾在LivingDamageEvent中按global.json的tacz.offhand_shield_damage_reduction（默认0.2）减免全类型最终伤害，射击和换弹不影响资格。统一经ShieldDurability使用正常hurtAndBreak，耐久成本为`1 + floor(窗口内累计减免前最终伤害 * 1.5)`，保留耐久附魔及不可破坏属性；完全吸收/取消/零伤害不扣耐久。主动格挡与被动盾按实际盾栈累计2 tick（0.1秒）承接伤害后统一磨损，不丢弃同窗口弹丸；换装备或保存前结清，减伤立即生效。换下任一物品立即失效，破盾不取消主手枪的使用。主动TaCZ盾减伤排除主手枪，避免重复减免及重复扣盾。

已开始并支付的TaCZ换弹绑定同一实际枪与枪ID。GunCustody临时收起/归还移动同一ItemStack，背包中的该枪仍可由原生tickReload脚本推进；原生计时、分段进弹、枪包规则及已有硬超时保留。只在原生换弹tick内部临时绑定收起的枪，返回时恢复真实主手供应，其他射击/速度操作不会把背包枪当作主手。归还时沿用已过去的进度，不重启或二次扣弹匣。移除/复制/手动替换枪、打开装备编辑、显式取消、死亡或超时终止授权，不恢复遗失枪或退款；卸载/重启仍沿用事务不持久化规则，不承诺跨卸载继续换弹。
