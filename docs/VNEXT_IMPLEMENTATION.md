# 新版本开发接入与验收账本

本文件记录源码责任与实际开发状态；玩法规格以知识库《本轮实施总指引》及其四个详细方案为准。用户已于本轮授权正式开发，静态审查通过后构建同步，部署后暂停等待用户游戏验收。方案中的早期“未授权实施”说明是历史状态，不能据此缩减当前任务。

## 统一入口与职责

| Module | Interface 与不变量 | 接入责任 |
|---|---|---|
| 阵营定义 | FactionDefinitions 的不可变 Revision；重载整表成功后发布，失败保留上一完整版本；未知 ID 不猜阵营 | 主控 |
| 人类身份 | HumanFactions；出生、旧加载与只读查询分开；同群一次选择、旧实体稳定迁移，team 仅派生值 | 主控 |
| 政治声望 | FactionStandingData 存真实值与每日额度；StandingPolicy 为唯一数值规则；不读取客户端配置或旧身份牌 | 主控 |
| 玩家绑带 | IdentityBands.selected；等级优先，同级按专用／通用／背包和稳定槽序；一次选择供关系、宽容和渲染使用 | 主控 |
| 关系与伤害许可 | 统一返回关系原因；有效雇主优先，政治／即时敌意独立；许可不制造视觉确认 | 主控，待接入 |
| 专精与有效属性 | SpecialtyAttributes / EffectiveAttributes；结果存档，查询不抽取；预算内含于乘数，仅输出散布取倒数 | 专精开发者，交付审核中 |
| 装备与补给 | FactionEquipment 系列集中候选、分档、概率和容量，现有生成入口只做适配；配置保持五文件 | 装备开发者，开发中 |
| 命令与自然状态 | OrderDistances 统一解析有效锚点、日常／追击范围；所有移动消费者读同一结果；小队批处理复用单兵写入口 | 命令开发者，开发中 |
| 界面与网络 | 服务端校验会话／权限／距离，只读快照；客户端不重算权威值；定义修订与实体身份同步 | 主控，待接入 |

不因职责集中而把所有规则塞进 Human.java / HumanGunner.java：这些文件只调用生命周期与事件入口。可选联动引用留在专用 Adapter。新状态必须有唯一所有者和清理／保存规则，消费者不得自行再存另一份权威状态。

## 完整范围检查表

- [ ] 数据底座：四阵营可重载定义、统一修订、生成来源、同群身份、旧迁移、未知数据保留、配置优先级和开关。
- [ ] 关系：同阵营跨阶友好／异阵营敌对；同雇主／不同雇主PvP；临时雇主到期；自卫／雇主保护；感知准入；已失效目标释放。
- [ ] 声望：七档、默认起点、真实损血、动作去重、致死合计-18、每日+30共享上限、目击不叠奖、可靠主人归因。
- [ ] 绑带：16物品、统一选择、有效声望、16玩家滚动宽容与越级群体敌意、无隔墙锁定、无Curios回退、旧槽物品安全返还。
- [ ] 雇佣：真实声望门槛、阵营信物与折扣、一次事务、旧契约不重复付费、重复包／失效对象安全拒绝。
- [ ] 属性：十一维全模型、正向准度、合并边界守恒、头目预算、标签／数据包、旧实体不重抽、未知schema保留。
- [ ] 实战数值：六原生属性、成长生命、近战／弓弩／三叉戟／三枪械后端、移动状态反复写基值、原生散布归属、heal精度和明确医疗兼容。
- [ ] 出生装备：全候选分档、韧性条件池、缺档回退、枪池与概率唯一、附魔合法性／诅咒、耐久、盾数量、补给权重和容量、弹药倍率、用户配置迁移。
- [ ] 命令：三模式、旧五枚举映射、半径唯一来源、驻守四组合、400tick有限追击／80tick回位等待、所有路径与局部移动消费者。
- [ ] 自然状态：稳定实例锚点与作者状态分开、64点路线／三模式／执行计时／回退、解雇恢复、跨维度安全、模板旋转镜像上下文、自检清理工具。
- [ ] 小队：8×32／16字符、UUID账本、未加载保留、正式雇员权限、批量部分成功、不强加载／不补发、令牌会话验证。
- [ ] 界面：三命令模式、单兵半径／驻守参数、名册编队和批量结果、属性详情每20tick按需快照、野外观察镜。
- [ ] 注册与呈现：12阵营普通蛋／9头目和蛋／旧蛋兼容、贡品箱外观、16绑带共用人类／玩家纹理与护甲层、纤细手臂、头目标尺。
- [ ] 身份牌退役：保留注册物品，移除功能／新掉落／配方；不清其他表条目；新绑带不加正式获取途径。
- [ ] 收尾：静态与自动化审查、可选依赖／专用服务端检查、构建、知识库机制正文与默认附录同步、已实施方案归档与未来项分开、目标停止后备份同步与三方哈希、暂停待用户验收。
